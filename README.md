# Independent systems landing page

A self-contained, dependency-free landing page for GitHub Pages. The responsive styles and small year script live in `index.html`; the `assets/` folder contains the project visuals.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Add `index.html`, the `assets/` folder, and this `README.md` to the repository's root.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select the branch containing these files and the `/ (root)` folder.
5. Save. GitHub will provide the public Pages URL.

The page does not need a build command, package manager, server, or Replit runtime.
